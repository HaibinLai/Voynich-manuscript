接续研究的 agent 指南

先确认正在读的是哪个实验，而不是把整个仓库当作一个“已破译结果”。网站是静态证据快照，不是后台运行监视器。七小时窗口及阶段状态见 research/research7h/session.json；过期的窗口不是继续无限运行的授权。

快速入口
1. README.md：范围、来源许可、复现命令及尚未证明的内容。
2. research/sources/provenance.json：原转写版本与哈希。
3. research/research7h/split_manifest.json：整叶划分；按实验规定使用数据。
4. 每个实验的 protocol/receipt/config：先读再运行；报告中的分母、目标集合和条件不同。
5. research/research7h/literature/：原论文索引、候选方案缺口与直接先例。

数据对象
EVA字母是字形代号，不是已知音值；空格片段不保证是真实词。原图与转写应并置，原文分歧和无法识别的字形不能为匹配候选名称而删除。20页、332位置的阅读框是近似行位，不是独立盲OCR或逐字专家终审。

train+legacy拟合，dev选参数，confirm是本项目多次探索后的已见集合。reserve仅指该实验未拟合/评分，不指公开手稿从未被阅读。曝光史见 reserve_exposure_log.txt。不要自行读取预留页结果后选择规则；应先冻结明确方案、输入、预算和报告范围。公开转写文件的下载/哈希/解析遍历，与把预留记录返回给模型是不同访问层次，报告必须诚实区分。

已完成的最终预留评估（stage3）
final_reserve/reserve_v1 已完成 22 页、11 叶的预定评估与独立复算；以下路径均相对 research/research7h/。它已不再是可供后续新假设使用的未见测试集。原 28 页 confirm 结果及密码替换搜索是另一实验，不与这里的分母或区间混用。
- final_reserve/report_v1/：完整中文报告、主 ZL 十项图、三表示三十项图、tables.json；manifest.json 绑定实际 summary、综合审核及六个报告输出。
- reserve_publication_manifest.json：125 个公开文件的字节与 SHA 清单；python3 scripts/verify_release.py 会同时检查此清单。清单之间有重叠，不能累加为独立文件数。
- final_reserve/reserve_v1/independent_review.json：综合审核门槛，绑定主完成记录、主/修正摘要、概率复算、汇总核验及 metadata 复算的哈希；不要用 preflight 完成记录替代。
- final_reserve/reserve_v1/independent_aggregate_audit.json：39 项主/辅助汇总、目标资格、来源坐标、保存 bootstrap 与六项位置尾概率/Holm 的核验。
- final_reserve/reserve_v1/independent_probability_replay/verification.json：12 个任务、111 个概率成本数组和全部 11,994 次位置置换的独立标量复算；同目录 position_*.json 给出三表示细项。
- metadata_sensitivity/reserve_v1/replay_verification.json 与 independent_aggregate_review.json/.txt：行内 H 修正的独立概率和 24 项汇总审核。旧分数保留，修正敏感性另列；等叶平均变化不是逐词影响上限。

最终预留包的安全复算命令（从仓库根运行；需要 NumPy，报告另需 Matplotlib 与中文字体；所有输出位置须尚不存在）：
python3 research/research7h/final_reserve/saved_output_audit.py --run research/research7h/final_reserve/reserve_v1 --mode reserve --output ../reserve-aggregate-check.json
python3 research/research7h/final_reserve/new_saved_replay/replay.py --run research/research7h/final_reserve/reserve_v1 --output ../reserve-probability-position-check
python3 research/research7h/metadata_sensitivity/replay.py --run research/research7h/metadata_sensitivity/reserve_v1 --out ../reserve-metadata-check.json
python3 research/research7h/final_reserve/report_saved.py --run research/research7h/final_reserve/reserve_v1 --output ../reserve-report-rebuilt

这些命令只复算保存包，不重新选参数或选择新目标。metadata 的 reserve_aggregate_review.py 无命令行输出参数，固定写入已存在的审核位置并拒绝覆盖；阅读其已保存收据即可，不直接在发布快照原地重跑。统一 --replay metadata 指向早先的公开确认集入口，不能代替上述最终预留 metadata 命令。

访问范围必须准确：legacy metadata replay 的 reserve_loaded=false 是冻结输出字段，不能解释为“没有接触预留目标”。传入 reserve_v1 时它会读取保存的预留目标，但不重开原始语料加载器；见 final_reserve/replay_scope_note.txt 及综合审核中的 saved_reserve_packet_read=true、raw_corpus_reopened=false。不要修改冻结程序来消除字段歧义。

跨行探索与上述预留评估分开：line_boundary_design/ 是只用允许 train+legacy/dev 记录的资格与设计审查；line_boundary_prediction/ 的协议、toy 核验和独立审核准备已冻结，freeze_status.json 是原设计冻结时的历史收据；后续 run_v1/complete.json 与 independent_audit/audit_report.json 已记录全部三表示的真实 dev 评价及 90 个选参点复算。执行范围仅为 train+legacy 内选参和 dev 描述性评价，不自动获得 confirm/reserve 新评分授权；需先核对当时的状态、执行门槛与剩余时间。合成校准结果不等于真实跨行结果。

复现习惯
先运行 python3 scripts/verify_release.py 核验公开快照。可选 --replay anchor copy allograph metadata --output 仓库外新目录，会调用四个保存证据复算入口；它不重新选参数，也不打开新分区。20页便携图文工作包由 scripts/export_review_bundle.py 生成，原始逐页JSON与JPEG保持字节不变。
优先使用各目录 public_reproduce / replay 入口，将新结果写入不存在的新目录。不要覆盖原协议、选参、随机数组、错误诊断或已完成分数。发现错误应保留旧记录、新增带时间和哈希的说明，再做明确版本的修复。错误修复与因为结果不理想而换模型不同。

多包有同名 models.py/reference_models.py；在同一Python进程随意改搜索路径可能导入错版本。使用隔离进程或明确唯一模块名，并核验实际类源文件。概率比较必须包括词尾、非空条件、未知身份和恢复原字形的成本；近形距离、条件互信息与完整词预测是不同统计量。

书手元数据另有已发现的范围问题：原实验使用页级H，f115r的H=@应结合行内H=2/3覆盖；旧模型把@当作一个类别，不能称它是第六位书手或完整真实书手控制。原冻结分数保留，行内覆盖的修正采用单独敏感性实验；不要静改旧parser后继续引用原哈希。I是插图类别，C才是Currier的手，H是Davis标签；这些分类也不等于已知词义。

结论门槛
line_boundary_calibration 的已知答案实验专门检查观察器失配：真实依赖不变时，目标符号重编码可使旧模型收益变负；真独立时两个近似预测器也可能有小正差。因此，固定预测器的对数收益不是互信息，也不是意义有无的分类器。--replay synthetic 可复算全部保存合成证据；首seed的9/180次CV网格另有独立审计。真实跨行探索见 line_boundary_prediction/研究报告.txt；不能把合成观察结果或其小幅开发集收益当作手稿角色编码的证据。
词频规律、模型预测收益、词典命中、植物相似、可恢复密钥均不能单独当作译文。语言/意义判断需要固定可执行规则、独立跨页对应、连续语法和能通过的阳性及阴性对照。直接先例须核查原论文；不要把本项目复核称作首次发现。三个转写/单位表示共享材料，不能当作三份独立手稿。

交付一个新实验时至少留下
- 一句话问题、明确可失败的预测、已知先例与当前暴露范围。
- 允许读取的数据、固定参数网格/预算/随机种子、目标/缺失计数。
- 所有预定结果、每页/每叶贡献、对照数组及不确定性条件。
- 来源与代码哈希、可复算入口、失败与局限、下一步还缺什么。

发布边界
只发布授权的历史手稿图、公开转写、自写代码/综述及许可清楚的第三方材料。现代论文全文、影印本现代序言、个人文件路径和凭证不进入仓库。原作者代码和语料保留原许可；转写的CC0不能扩展成图像或字体的许可。站点用 scripts/build_site_data.py 重建，资料导出用显式白名单，不全目录复制私人工作区。
