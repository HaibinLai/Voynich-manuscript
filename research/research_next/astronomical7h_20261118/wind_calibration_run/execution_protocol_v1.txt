First conditional wind-matrix execution, version 1

This is a computational execution plan following input_contract_v1.txt, not a new input or editorial rule. The frozen source input already includes all 48 original fields, explicit catalogue/image identities, two representations and all 25 blocks. It contains observed-source uncertainty and declared catalogue assumptions. No real matching has yet been executed by the root adapter when this plan is written.

Requirements before execution
1. The independent input review must be complete and frozen, with no unresolved substantive input/adapter error. Its approval must be explicitly limited to catalogue-conditional partial-content measurement, not full physical transcription.
2. The artificial engine, 94-check fixture report, input preparation contract, input JSON and adapter must still match their freezes. Any changed implementation or input requires another version and another review; do not silently update a file inside an existing freeze.
3. A separate execution_approval_v1.json binds the exact reviewed input, engine, adapter, contract and independent review hashes. It authorizes only this conditional experiment. The actual execution command is read-only and writes JSON to stdout.

Execution and evidence retention
Run all four combinations in the fixed order E0/f1v, E0/f2r, S1/f1v, S1/f2r. Each contains all 144 cells, all twelve offsets, both named delta definitions, per-cell evidence and source tracing. There are 576 cells in total; they are not independent historical samples.
Save the complete stdout unchanged as results_v1.json, then freeze its hash, command, code/input hashes and timestamps before inspecting or announcing numerical outcomes. A separate report may interpret the frozen result but must not change it. No outcome, including all-zero or inconclusive bounds, authorizes a new spelling, subset, phase, alias or normalization.

Point estimates and partial content
The full matrix may be incomplete while a specific phase such as T0 is nevertheless exactly identified by known occurrences. Report an exact phase only where every one of its twelve binary values is identified. Keep the complete primary delta point estimate NA if any relevant binary value remains unresolved; show its conservative fixed-denominator bounds instead. Unknowns never become zeros. Do not infer exact ranks from overlapping intervals.
Every 1 must have a whole-token occurrence witness within a single known run/block, every 0 must have fully given content without a witness, and every NA must retain its source uncertainty reason. The unknown-to-cell map records shared origin; independent-cell bounds are deliberately not claimed sharp.

Independent numerical replay
After the result is frozen, give another implementation the same approved input and result for full recomputation. It must not import the engine or adapter or use stored totals as its calculation. Compare all 576 cells, known occurrence locations/blocks, unknown reasons, all 48 phase records, both delta definitions, their exact 12/11 relationship and any available point/tie quantities. A source-preservation review is not a substitute for this numerical replay. Independent code is not a second paleographer or historical sample.

Interpretation and publication
Report each leaf and both representations. A positive lower bound is a conditional recurrence advantage under the relaxed unknown completions; it is not a word-meaning proof. A bound containing zero leaves the sign unresolved. Describe missingness and the full-image certification gate prominently. Do not infer that wind diagrams are the content or source of the Voynich manuscript. Keep f67r2's full-text prediction unexecuted under its unchanged measurement gate.
Publish the complete approved inputs, scripts, results, limits and numerical audit after the audit has completed, and add an interactive matrix/offset view with raw source fields. Unfinished other agents' observations remain outside the publication. The seven-hour endpoint and remaining zodiac scope are unchanged.
