# 独立数值复算器 v1

本目录的核心计算器独立编写，未读取根目录 `method_engine` 的代码或结果；实现冻结之前未读取新 `feature_observation`、新图像或真实形态值。仅使用四项指定合同文件：`feature_codebook_v1.json`、`measurement_approval_v1.json`、`measurement_review/review_v1.txt` 和 `baseline_snapshot_v1.json`。历史快照包含既有文字描述，因此这里不声称盲设计、独立形态证据或独立人工审图。

## 输入

`input_schema_v1.json` 描述接口。输入必须包含 `schema: canonical_allowed_domains_v1`、`frozen: true`，以及 `groups` 映射。`groups` 的键恰好是审批文件的12个 canonical group ID；每组有 G1–G4 四个键，每值为 `[0]`、`[1]` 或 `[0,1]`。未冻结、空域、缺少组或特征、额外组或特征、null、非二元状态均拒绝。实现不对证据冲突自行改码；证据交集若为空必须在适配阶段拒绝。`frozen: true` 是输入声明，不代替根对观察文件及读取回执的实际冻结审核。

真实观察文件冻结后，若字段不匹配，可新增仅负责格式转换及一致性检查的适配器。核心实现冻结在先；不得为了吻合另一实现的结果改动逻辑。所有适配器与结果另行记录哈希。

## 运算

1. 从九节点的 label/leaf 独立生成36个无序对。核对27个跨叶对和三个混合层分母 `(1,2)`、`(2,10)`、`(2,2)`，即19对中的5同14异；并与两份冻结配对表逐项核对权重。
2. 固定一个完整候选。每特征只对该候选实际引用的 canonical 组建立一次变量，枚举其允许域笛卡尔积。不同位置引用同组必然复用同一状态；同状态在全部配对共享。
3. 用精确有理数计算每层的同标签相等率减异标签相等率，三层等权。保留同权 T11 和 T00，严格有 T=T11+T00。
4. 在同一候选内，先对各特征分别取极值，再四特征等权平均；最后从16个完整候选中取全局上下界。没有逐对或逐特征择取候选。

输出包含16个候选、每候选36对的四特征范围及固定分母4的平均范围；每特征总量与逐层的 T/T11/T00 极值、canonical 与节点回映见证、层内次数与分母；全局端点的同一候选及四特征见证。逐层极值不能平均替代整体极值。独立优化的 T11/T00 范围不可相加；只有同一个 T 端点附带的分解才严格相加。

补全域明确放宽为按特征和组分离的二元笛卡尔积。由此得到的是**保守外界**；代数见证不保证具有共同可实现的绘图或生物形态。不是生物学锐界、置信区间或 p 值。36对不是36个独立样本。

## 玩具验证与冻结

`test_replay.py` 使用虚构四节点例子，检查共同缺少使 T=2/3 而 T11=-1/3、T00=1；未知不填0；全局共享未知；canonical重用；完整候选共同选择；空域、未冻结、缺项、null及零混合分母拒绝。另用40个固定随机种子的两特征小例，把分特征优化与另一段直接联合穷举的公式比较。玩具文件中的形态状态均为虚构，不是九位置的观察。

运行玩具检验：`python3 test_replay.py`。冻结清单见 `implementation_freeze_v1.json`。真实数据计算命令为 `python3 replay.py --domains FROZEN_DOMAIN_FILE --output REPLAY_RESULT_FILE`。核心仅用 Python 标准库，兼容当前 Python 3.9。
