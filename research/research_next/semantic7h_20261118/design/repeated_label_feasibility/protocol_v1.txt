Repeated-label image experiment: feasibility inventory only
2026-11-18. Exploratory selection from already exposed transcriptions.

Question: are there enough cross-physical-leaf repeated full labels, with
agreed readings and existing object locations, to freeze a later anonymous
same-label versus different-label image comparison? No image comparison,
species identification, lexical-body match, or semantic score is performed.

Sources: the original ZL3b-n and IT2a-n IVTFF files, existing Yale IIIF manifest,
and source-localization fields of already completed image reviews. No new
images are viewed. Prior target similarity judgments and lexical outcomes are
not selection criteria. Existing combined object-registry metadata were
briefly inspected to locate source files; selection uses the original source
records and source-box fields directly, not that registry's lexical results.

Unit: a locus classified as a label in either version. All such loci are
retained in the inventory with both raw records, type and exclusion reasons.
Lp (plant), Lf (plant fragment), Lc (container), L0 (unspecified) and all other
types remain separate. Lf is reported as a separate possible fragment stratum;
it is not silently merged into Lp or authorized as a new experiment.

Strict single-label eligibility: both versions contain the same locus; same
label subtype; each contains exactly one complete, certain word; and the
entire reading agrees. Certain/uncertain separators (period/comma), alternate
readings, unknown characters, graphic interruptions, internal annotations and
unparsed character syntax are exclusion reasons, not repaired. Boundary
annotation tags may be stripped. Atomic extended EVA @ddd; is retained as
one known encoded unit. Ligature/brace and apostrophe syntax is retained in
the raw record but excluded from this minimal exact-reading inventory; no
canonicalization is introduced to enlarge support. Multiword labels are
excluded intact; no convenient component word is selected.

Physical leaf is the leading f-number: recto/verso and foldout panels sharing
that number are the same physical leaf. Repetition requires the same agreed
full label at eligible loci on at least two physical leaves, within a subtype.
All eligible singleton labels and all rejected records remain available.

An existing object box is evidence of prior approximate localization only.
The box and its official image URL, source record, locator attribution and
any ambiguity are retained. A box is not a semantic gold object, nor does its
presence establish that the adjacent writing names it. Label-only boxes and
whole-page image availability are not counted as object boxes. Multiple
candidate objects or several labels associated with a box remain unresolved.

The feasibility output reports all clusters and all their members, source
leaf counts, official canvas candidates and existing source-object boxes. No
cluster is retained or rejected by how its drawings look. No matching body
text, substring expansion, spelling changes, three-word joining, or new label
interpretation is permitted. If cross-leaf repeat support with uniquely
attributed pre-existing boxes is absent, report insufficiency without relaxing
these criteria. Any future comparison requires a separately frozen protocol,
complete inclusion roster, masked text, leaf-aware controls and independent
review; this inventory is not a new blind confirmation set.
