The confirm structural outcomes have now been examined. Predictive architectures below derive from the earlier stage1 protocol, but this detailed implementation freeze occurs afterwards. Do not call all task-level evaluation fully blind.

Unit model: train-only alphabet plus EOS and UNK; each token begins fresh BOS context, so models do not borrow the next word. Interpolated Dirichlet n-grams of order 1..4, with strength alpha in {1,5,20,100}. At zero-history use symmetric smoothing toward a uniform distribution; at higher history use P(c|h)=(count(h,c)+alpha P(c|suffix(h)))/(count(h)+alpha). Include EOS in scored events. Unseen extended symbols map to UNK, count and report. For each order choose alpha on dev; choose best order for later models by mean held-out dev bits per event.
Global word model: empirical train token counts mixed with the best char model: P(w)=(count(w)+beta Pchar(w))/(N+beta), beta in {10,100,1000,10000}, dev-selected. This allows nonzero mass for unseen words and is normalized over finite strings, including technically possible empty output. No dictionary or decoding target.
Known position conditioning: train 3 character models for explicit paragraph-initial token, other physical-line-first token, remaining token; model P=(1-lambda)Pglobal+lambda Pposition with lambda in {0,.25,.5,.75,1}, dev-selected. Report improvement vs same selected global model for exactly the same targets. Position is externally known from document layout, not predicted semantic information. Unknown paragraph context and missing slots are classified without pretending the first retained token is the first slot.
Hand conditioning: analogous global/hand char model mixture, train metadata hands; same lambda grid; unseen hand falls back to global. Hand labels are source annotations and not causal truth.
Sequential word cache: P=(1-lambda)Pword+lambda Pcache, lambda {0,.05,.1,.2,.4}, window {1,4,8,16}; Pcache empirical preceding valid words, reset at each physical line, unknown slots clear the history. When empty history P=Pword. Use previous *observed* words, not generated words (teacher forcing). No future tokens. Tune solely on dev token-mean bits. Compare same scored tokens under left-to-right and reverse context, and one fixed within-line permutation. Reverse is exploratory and not a temporal causality test; shuffled cache score evaluates real targets with context from a permuted line and must describe that clearly. Main original-context score is primary predictive measure.
Metrics: pooled bits/token and bits/(unit+EOS), page-mean bits/token, per-page difference, and paired leaf bootstrap interval (1999 resamples). Intervals conditional on chosen sample/algorithm; primary population is these leaves. No model family is treated as a decipherment. Report all n-gram orders and selected configuration even if more complex models lose.
Versions: ZL/EVA primary; IT sensitivity with same data split and independent dev tuning; merged-unit ZL sensitivity. Compare within-representation improvements only, not raw bits across differing alphabets.
