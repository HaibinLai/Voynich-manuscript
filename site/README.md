# 研究台网站

这是纯静态 HTML / CSS / JavaScript 网站，无构建依赖、外部脚本、分析跟踪或第三方字体请求。所有资源路径均为相对路径，适配 GitHub Pages 的 `/Voynich-manuscript/` 子路径。

## 更新数据

在仓库根目录运行，参数指向包含 `study20/`、`sources/` 和可选 `research7h/` 的本地研究数据目录：

```sh
python3 scripts/build_site_data.py --source /path/to/voynich
```

构建器只复制列入清单的 20 页手稿 JPEG、40 个疑难区域与指定研究输出。不会复制原始 PDF、现代序言、学术附文或用户本机路径。

## 本地预览

```sh
python3 -m http.server 8000 --directory site
```

访问 `http://localhost:8000/`。页面通过 `fetch` 读取 JSON，不应直接以 `file://` 打开。

## 数据接口

- `data/overview.json`：样本说明、来源、20 页选择信息。
- `data/homepage.json`：当前证据概览、图文核对范围、执行状态快照与实际复算收据入口。
- `data/final-reserve.json`：真实保留集执行与复核尚未全部绑定时只有状态、`available:false`，没有预演数值；完成后提供完整固定比较与敏感性。
- `data/folios/{folio}.json`：两版转写、分歧标志、重点复核与原图校验值。
- `data/folios/{folio}.json` 的 `high_resolution_review`：该页逐位置观察、原始两版字符串及相对于耶鲁完整 JPEG 的归一化阅读框。
- `data/high-resolution-review.json` 与 `downloads/high-resolution-verification.json`：20 页 / 332 处的合并高清复核和覆盖核验；构建时校验合并记录哈希，防止核验与数据错配。
- `data/statistics.json`：全部 15 次统计运行及随机对照原始数组。
- `data/literature.json`：文献证据表；未发布时为空数组，不以占位论文充数。
- `data/candidate_claims.json`：候选解读核查记录。
- `data/interpretation-audit.json`：候选规则覆盖、章节/书手共同支持、页级 H 范围说明和保留集预演状态的展示摘要。
- `data/anchor-audit.json`：四组正文词形 × 两个 m 处理界限的规则覆盖、分母来源及三张耶鲁裁图的观察记录；不是译文率。
- `data/metadata-sensitivity.json`：固定旧参数、展开明确行内 H 后的全部 24 项完整词模型敏感性；原数值不覆盖。
- `data/calibration.json`：已知答案的人工密码校准；恢复映射不等于手稿译文。
- `data/research.json`：研究状态的静态快照，不是后台实时监控。
- `data/stage2.json`：段首完整成本、完整词边界预测、生成机制、复制预测与灵敏度校准，保留各自样本范围。
- `data/boundary-diagnostic.json`、`data/boundary-fullword.json`：边界诊断与完整词后续模型的原始公开摘要。
- `data/boundary-calibration.json`：人工 12 词行的 181 次灵敏度校准，不与真实叶组分析混合。
- `data/boundary-prior-art.json`：边界依赖的直接先例、位置混杂研究与相关假说；条目注明与本轮工作的关系。
- `data/copy-prediction.json`：完整词复制预测的全部公开摘要，包括 80 次 Timm 校准、三个手稿表示、九项主要比较与独立复算结果；仅在核验通过后导出。
- `data/sources.json`：公开原始材料、来源 URL、转写校验值与许可范围。
- `data/manifest.json`：公开数据、图像、HTML、CSS 与 JavaScript 的 SHA-256 校验值。

首页主区域展示当前证据，四张卡片分别通向段首、不同生成机制、更强相邻对照、跨词与可逆字形预测的准确面板。每项保留自己的取样范围，不合并不同实验的分母；首轮 20 页四项统计默认折叠为历史记录。人工审定的概览文字位于 `content/overview-curation.json`，构建时与实际研究状态组合；它不覆盖执行记录。

首页与研究日记共用阶段快照。密码搜索只读 `progress.json` 的状态、完成数、预算和时间，不读运行中的评分文件。保留集状态依次检查开封记录、主评分完成记录、标签敏感性完成记录、绑定结果哈希的独立复核；预演通过不会被当作保留集完成。构建器只读取状态收据和分区页/叶元数据，不加载保留集词形或结果数组。`interpretation-audit.json` 中预演记录只保留历史范围，当前执行状态统一以 `homepage.json` 为准。

首页的“核验与复算”进入统一说明，可下载四类保存证据实际复算收据。收据绑定当时的数据提交与脚本哈希，不自动认证之后的网页修改。仓库根目录运行 `python scripts/verify_release.py`，仅用标准库检查发布文件；按说明另行运行保存证据复算时，应使用仓库外的新输出目录。`scripts/export_review_bundle.py` 可在本地生成 20 页图像、40 处裁图和 332 处双版记录的便携包，网站只提供入口。

面板深链接使用 `#journal?study=面板ID`。路由会展开目标所在的证据区并将键盘焦点移到目标；原图、文献和复现入口仍直接可达。

保留集展示入口在 `final-reserve.js`，只在完整复核后生成面板。构建器先核验 `reserve_opened.json`、真实 reserve 模式的 `complete.json`、标签修正 `complete.json` 与 `replay_verification.json` 的成功状态；最终 `independent_review.json` 必须绑定 `complete_sha256`、`metadata_complete_sha256`、`metadata_replay_sha256`，还须以 `summary_sha256` 和 `metadata_summary_sha256` 分别绑定两份实际结果摘要，才读取数值。真实摘要必须为 `mode=reserve/split=reserve` 且匹配冻结方案；没有 confirm/preflight 回退路径。未通过门槛时不产生长空面板，不导出结果下载；临时界面 fixture 只能位于研究目录之外。

最终面板固定顺序完整展示主 ZL 十项、两表示二十项敏感性、九项总体比例恢复、六项位置辅助及统一 Holm、全部曝光叶剔除描述与二十四项行内 H 修正。95%、主十项族 99.5%、全三十项族 99.833333…% 区间原样可展开，不按数值排序、不设置新的判定阈值，跨零不标“无效”。主增益采用页内词均→叶内合格页面等均→合格叶等均；成本拆分明确使用所有词合并平均，escape 是已计入的组成项。合格目标数、页、叶分别列出，不能混用不同分母。可滚动表格能获得键盘焦点。

阶段一的 `downloads/stage1-report.txt` 与 `assets/stage1-results.png/.svg` 由构建器明确复制，并在进展页标注 28 页确认集、13 个叶组与 5,025 个词形。这是与旧 20 页研究不同的实验。阶段一完成不会将总研究状态改为完成。

第二阶段的报告、图和核验资料也使用明确清单导出；实验各自完成不会修改总研究状态。边界依赖已有 Currier、Smith–Ponzi 等直接先例，本轮属于复核和模型外推。小样本人工行校准独立展示，不与真实手稿叶均值放在同一尺度比较；自然拉丁文本未检出优势也不能用于排除语言。

完整词复制预测单独展示 Timm 正控的检测响应及手稿三种表示的小幅增益，保留 95% 与每表示三个主差的保守 98.333% 区间。IT 跨零、单编辑没有稳定胜过精确复制、此前确认集探索已影响方案等限制均直接显示。`downloads/copy-prediction-*` 提供报告、冻结方案与独立核验，`assets/copy-prediction-results.png/.svg` 提供原结果图；大体积来源审计文件由研究目录维护，不复制进网站。

位置特异性面板提供六项完整结果与 120 条件生成器校准。相同长度换位保留约 77%–91% 的上一行预测增益，只扰动 V 来源通道，不能描述为全篇打乱；六项均无清晰的精确位置独特证据。`data/position-specificity.json` 保留原公开摘要与置换数组，进展页数据省略大数组以减少重复；报告、图、方案和复算记录由明确白名单导出，探索性 p 值、移动比例和保留集未评分等限制直接显示。

可逆字形合并面板提供 `data/allograph-factor.json` 的全部九组主结果，含条件恢复与总体比例恢复的对照。k/t 总体恢复在三种表示均为负，只有条件恢复才获得小收益，不能推断为同字母。折叠证据给出全部恢复费用、保守区间、45 次已知机制校准与容量/调参预算限制，明确词形加权成本和叶等权增益的区别。三种归一化表示不是独立证据；实验通过独立复算才导出。

候选审查按四组 × 两种 m 条件完整展示 8 行规则覆盖。分母是固定解析器保留的正文词形出现次数，疑难整词、标签与圆环等不混入分母；单一符号路径不等于正确读音。独立路径计数、公开前向复算和同解析器来源重建均通过才导出，构建时检查冻结覆盖结果及词形记录哈希。三张 `assets/anchors/*.png` 只来自耶鲁手稿；与已核验的裁图哈希逐一匹配，不发布现代论文页面或整张高清原图。f41v 的 e/o 分歧与末尾 l 保留分开说明，修订记录可下载。

章节/书手审查只展示页与叶的共同支持，不把词频聚类当作词义；下载表中的词数来自密码实验的基本字母过滤版本，与完整词模型不同。尚未运行章节预测模型，计划也没有加入已冻结的保留集检验。

既有“书手条件”模型使用 IVTFF 页级 H 标签：原模型未展开 f115r 页内 H=2 / H=3，页头 `@` 被建为独立类别，不是第六位书手。日记及阶段一结果旁保留此范围提示，原冻结数值不改。修正敏感性在提示下折叠展示全部 24 行原/新等叶增益、差值、目标数及最大逐词模型成本变化；24 项平均增益最大变化不是逐词影响上限，没有新增显著性或区间。段首 12 组数组不变，IT 变异复制相对精确复制仍为负。报告、图及三类复算记录按公共清单核验哈希才导出。该项探索未使用保留集，保留集当前执行状态另见阶段快照。

每页 `yale_image.source_url` 提供官方高清原图链接及尺寸/哈希。默认页面仍用原有扫描，不将整套高清图重复打包。官方图像清单为 `https://collections.library.yale.edu/manifests/2002046`；图像权利信息与转写 CC0 许可分开记录。

逐位置列表可以展开阅读而不请求高清 JPEG。只有点击“加载高清图并定位”或原转写中的“高清定位”时，才从耶鲁加载对应完整图；叠框从归一化坐标映射到这张图，并检查实际尺寸与收据一致。框不叠加到裁切不同的 PDF 图上。窗口支持多框、适合阅读区/整页/原尺寸和横向滚动；失败时保留官方原图链接、重试与低清对照。332 处是位置对应核对，不是独立盲转写、逐字认证或译文；粗框可以包含邻近笔画。

f57v 的折叠对照图按 ZL 组成四行 17 列，保留 IT 末尾 `r | n` 两项；不宣称 17 字母表。D’Imperio（1978，印刷页 25）和 Stolfi Notes 034 是已有先例。四个第 9 格按钮从保存的角度/半径范围推导显示用矩形，在同一耶鲁原图上定位 f / f / p / p；构建器检查原图与对照图哈希。这些矩形不增加 332 处记录计数，也不认证字形身份。仅增加阅读辅助裁图，整套高清 JPEG 仍不打包。

构建器的快照时间取源材料的最新修改时间，不使用构建时钟；源材料不变时，连续运行产生逐字节一致的公开文件和校验清单。

## 解释边界

20 页已做版面和转写位置核对，另有 40 处重点字形/空格复核；不是逐字符终审，也不是两个独立专家转写。黄色只表示字符串不同。EVA 是字形编码，统计规律不是译文。原图为研究用 PDF 内手稿扫描；此站不含现代版权附文。

转写来源为 Zandbergen–Landini ZL3b 与 IT2a；版本和原始来源随研究数据记录，发布方在 [Licences and copyright](https://voynich.nu/roadmap.html) 说明转写资料采用 CC0。EVA 字体不适用该许可，本站没有嵌入。RF 的来源包含 ZL，没有作为独立确认票数。
