参数共享后续实验：独立设计审查与可执行建议
状态：设计建议，交由 root 冻结最终协议。本审查未拟合新手稿模型、未运行手稿评价、未修改旧实验包。已阅读旧 allograph_factor/protocol.txt；后续频数与维度信息由 root 提供，不是本审查另行测量的结果。

一、推荐的主问题与结论边界
主问题应缩小为：在固定的原单位自回归模型、相同局部曲率自由度及训练内匹配的对照下，对 FP、KT 历史系数施加定向收缩，是否比普通 ridge 或其他相近频数/位置分布的符号对带来更好的样本外预测？
主模型推荐凸多项逻辑回归，不先上 GRU。固定 3 单位历史的加性 one-hot 特征、截距及绝对生成位置特征。所有条件保留同一原单位输出、EOS、非空支持和相同稀有身份费用。
这个模型检验的是定向正则化，不是历史异体字、同音、语义或破译。有限强度的融合惩罚保留两个历史身份；它并不真正压缩输入。也不复现旧 quotient + restoration：旧恢复器能看已编码的整个商词及元数据，本模型只有原单位前缀。不能把两轮数值直接作同一模型的增强或失败。

二、为什么不以硬共享 embedding 为唯一主实验
令两个 embedding 完全相等，会同时减少可表达的历史区分和可估计方向。仅保持神经网络名义参数个数，或补上未被使用的参数，不等于控制有效容量。
可以用正交的共同/差异坐标解释：mu=(theta_a+theta_b)/sqrt(2)，delta=(theta_a-theta_b)/sqrt(2)。普通 ridge 对两方向同等收缩；定向融合更强地收缩 delta；硬共享是 delta=0 的限制。有限融合不消灭身份信息，允许数据克服先验；硬共享会不可逆地抹去历史区分。二者不能混称。
因此主实验用固定强度软融合。硬共享可在独立预定的合成机制检查中作诊断，不临时加入真实手稿主表。正结果最多支持这种收缩方向有预测价值。

三、原单位支持、稀有单位和位置
采用 root 提议：仅训练出现频次 >=20 的单位进入 COMMON。其余整个固定原宇宙 Ω（EVA1027：a-z、直撇号、@000;..@999;）统一为 OTHER，包括训练见过但低频的单位。BOS 是专门历史符号，OTHER 与任何实际原单位都不同。
这是预定的稀有身份折叠，不是只对未见符号做 escape。所有模型使用完全相同 COMMON 集、OTHER 和 Ω。COMMON 仅由训练数据确定；ZL/IT 各自训练确定，不用合并后的两版词表，不用 dev 或旧50页补字母。
输出类为 COMMON + OTHER + EOS。每次 OTHER 原单位目标的完整费用为 -log2 P(OTHER|history) + log2(|Ω\COMMON|)。训练时 OTHER 事件也付相同身份常数，虽然常数不影响系数/Hessian；报告总费用仍须加回。历史中的 OTHER 不另收费；原身份已经在该目标位置付过一次。训练/评价出现 Ω 外单位必须报错，不能过滤到某个好看的子串。
每个词重置历史为 3 个 BOS。绝对位置 j 为当前已生成的原单位数：0,1,...,15,>=16；EOS 也在当前 j 处预测。位置不能使用最终词长、真实末位角色、下一单位或其他未来信息。该特征能表达长度危险率但不会泄漏词长。
首步 j=0 禁止 EOS，其余步允许 EOS。有限历史字母表、有限位置桶和有限系数给出有限状态；每个非首状态 EOS 概率严格正，故存在正的最小结束概率，非空完整串总质量为1。实现用 log-softmax，避免把浮点下溢的概率0当成数学支持被删除。

四、设计矩阵、参考输出与融合矩阵
设 C=|COMMON|；输入维数 d=1 + 3(C+2) +17。每一历史槽完整 one-hot 包括 COMMON、OTHER、BOS；另有截距及17位置桶。输出类 K=C+2。固定 EOS logit=0，系数 B 为 d×(K-1)，不增加输出合并或恢复模型。
完整 one-hot 与截距有线性冗余；正的全系数 ridge 使优化问题严格凸，冗余无需偷偷改成因条件而异的参考输入编码。截距和位置系数也包含在基础 I 惩罚中，避免未见输出/首步等导致无界系数。不能在不同条件改为不惩罚截距。
固定 EOS 参考消除了输出平移 gauge；参考类下的 I 惩罚依赖此参数化，并非输出标签置换不变的各向同性先验。所有条件始终使用同一 EOS 参考，报告这一限制。若改为正交中心化输出对比编码，必须在实验前全体一起改，不混用两套惩罚。
对每个历史槽及选定符号对 (a,b)，定义 v=(e_a-e_b)/sqrt(2)。L_pair 为这些 vv^T 的和，只作用在历史特征行，不作用截距/位置/BOS/OTHER。FP 和 KT 条件各有3个单位差异方向，FP+KT有6个；替代双对必须互不重叠，保持相同秩。
P=I+10 L_pair；普通 ridge 为 P=I。r=10 意味着差异方向的总惩罚为共同方向的11倍，不是10倍。目标函数为每个完整词的总负自然对数似然的平均值（该词所有单位及 EOS 均计入）加 lambda/2 * sum_class b_class^T P b_class。不要把和损失与均值损失下的 lambda 混用。特征不另作依据评价数据的标准化。
目标 FP/KT 成员均须为训练 COMMON；否则该条件不具有所声称的可辨识方向，必须在评分前记为预条件不满足，而不是改成 OTHER 对或补入评价字母。

五、首步 mask、Hessian 和局部自由度
对上下文 i，x_i 为输入向量，n_i 为聚合事件数，y_i 为目标计数。可以按完全相同的（3历史、位置桶、首步mask）聚合，保留类别计数；这是同一似然的精确计算压缩。
一般步 logits=(B^T x_i,0)，p_i 为 softmax。取非 EOS 分量 q_i，H_i 的输出块为 diag(q_i)-q_i q_i^T。首步把 EOS 排除后，对剩余 K-1 类重新归一；同一公式成立，但秩下降1，这是正确的 mask Hessian，不应补回 EOS 的概率或曲率。
H = sum_i n_i/N_words * [(diag(q_i)-q_i q_i^T) ⊗ x_i x_i^T]，具体 Kronecker 顺序须与参数展平顺序一致。
A = H + lambda*(I_output ⊗ P)。定义 D_local=tr(A^{-1}H)，H 在该 lambda 的已收敛拟合点计算。用 Cholesky 解矩阵方程求 trace，不显式求逆。全部 FP64。
这一数值是固定设计、固定惩罚的局部响应/曲率自由度，不是精确有限样本泛化自由度，也不是模型表达能力的全描述。匹配它只能控制一个明确的容量指标；它不包含 COMMON、替代pair或候选假说的历史选择成本。不能据同 D_local 宣称等有效容量。
固定 H 时随 lambda 的 trace 单调，但重新拟合后 H 随 lambda 改变；不预设整个拟合路径全局单调。不要借线性 ridge 的单调公式为逻辑回归路径作未证明的保证。

六、两个 DF 目标、有限 lambda 搜索与失败规则
推荐候选目标 D=50、150，二者全部报告，不用 dev 选择哪个更好。只允许通过训练特征维度/秩上界和合成数值基准确认可计算性；不得先看手稿评价后调目标。若任一表示的训练维度上界或合成数值测试使目标不可行，应先公开修订协议并重新冻结，或将该目标记为不可实现；不临时悄悄降维。
按完整词平均的总 NLL 下固定 log10(lambda)=-8,-7,...,0,1，共10点。按强正则到弱正则确定性热启动，保存全部已收敛的 lambda、目标值、梯度、D_local。不得为某个目标无限扩展范围。
每个 DF 目标检查相邻已收敛网格点的符号交叉。如果多处交叉，固定选择最强正则化的那个括号（较大的 lambda 区间），同时报告非单调性。若无括号，记该目标失败，不取最近但超容差的解冒充匹配。
在所选括号中最多12次几何中点细分，保存每次；按符号保留仍跨目标的子区间。若出现非有限数、局部求解失败或不能保持括号，停止该目标并记录，不越过失败区假设连续。已达到容差可提前结束；并列解固定取较大的 lambda。
容差为 |D_local-D| <= max(0.1,0.002D)，即50±0.1、150±0.3。所有比较列出实际 DF 和残差，不能只写标称值。每个惩罚配置最多10+2×12=34次拟合（缓存同一 lambda 可减少，不增加上限）。
凸优化建议：零起点用于最强 lambda，其后从最近已成功 lambda 热启动；阻尼 Newton + Cholesky，Armijo 系数1e-4、步长从1最多尝试30个减半步长、每次拟合最多50个 Newton 更新。root 已采纳梯度无穷范数 <=1e-8，且全系数 ridge 的强凸性上界 ||grad Q||_2^2/(2lambda) <=1e-8 nats/词；两者同时成立才判收敛，每步均保存。该上界使用 P 的最小特征值>=1；不能把它误写成未惩罚似然的误差界。
未同时满足收敛和 DF 容差即失败。不得在 dev/旧50页结果出现后增加步数、放宽容差或换目标。合成基准阶段若50步太少可整体修订再冻结；正式运行后所有失败条件留在主表，不只保留成功者。
Cholesky 失败不能静默加入改变科学目标的 jitter。先保留矩阵/诊断，再按预定的一次 CPU FP64 同目标复核；若仍失败，记录并停止该格。求解残差与H对称误差都存档；不同GPU调度允许数值容差内差异，不宣称模型字节级确定性。

七、训练内配对参照与有限规模（按 root 最新三参照方案）
普通 ridge 在每个 DF 目标各拟合一次，可被多个对比共享。目标条件为 FP、KT、双对，不以某版先前优势挑选。
候选为训练 COMMON 中两个不同合法原单位的无序pair，排除恰好 FP 与 KT，不含 BOS/OTHER。允许控制pair共享成员，亦允许使用目标pair中的某个成员；这意味着并非独立随机null，要公开每个候选的组成。全部控制必须在任何dev/旧50页模型评分前确定。
明确距离建议如下。每个单位 u 计算训练出现数 n_u、绝对位置 j=0..15/>=16 的17维分布 p_u、single/first/middle/last 的4维角色分布 r_u。每个直方图格加0.5再归一；single 不重复计入 first/last。角色仅用于训练边际匹配，不输入预测模型。
每个pair按 n 从高到低定向，并列以原单位字符串字典序定向。设候选两成员为 c_1,c_2，目标为 t_1,t_2，定义
D(c,t)=0.5*sum_{i=1,2}[log2((n_ci+0.5)/(n_ti+0.5))]^2
       +2*sum_{i=1,2} JS_bits(p_ci,p_ti)
       +2*sum_{i=1,2} JS_bits(r_ci,r_ti)。
JS_bits(P,Q)=0.5 KL_bits(P||(P+Q)/2)+0.5 KL_bits(Q||(P+Q)/2)。所有量仅训练内计算；用math.fsum与FP64。按(round(D,12), canonical_pair)排序，取3个不同pair，保留全部；不看模型分数再删。
须同时导出原始计数、每成员计数比、17/4维平滑分布、频数项和各JS项，不能把距离小当作严格匹配证明。没有额外事后caliper；若3个近邻仍差很大，结论明确受匹配不足限制，不换更有利控制。
双对参照把两个不同候选pair组成bundle，按 min[D(a,FP)+D(b,KT),D(b,FP)+D(a,KT)] 排序，canonical bundle字典序打破12位舍入后的并列。不得把同一个pair重复两次。审查推荐bundle内部也不共享成员，使每历史槽L的非零谱固定为(1,1)。若root最终允许内部共享成员，必须冻结并报告：共享一个成员时谱为(0.5,1.5)，普通双对为(1,1)，二者同秩/迹但收缩几何不同，DF匹配不会消除此混杂。候选bundle全部列出共享状态，不能称完全同惩罚形状。
三目标各3参照：每表示1普通+3目标+9参照=13配置；两表示26配置，每配置最多34个lambda拟合，即至多884次有界拟合。可重用完全相同惩罚配置的拟合，但不能把重复计算当作独立结果。8张V100可按配置并行，一GPU一个确定性任务队列；所有条件FP64。不以dev选择控制数量。
约1.8k参数的单个FP64 Hessian约26MB，多个矩阵/优化状态另计。主要成本是重复构建H而非仅Cholesky。每个输入仅截距、3历史、1位置共5个非零特征，可按25个特征块累加输出协方差；避免建立“上下文数×完整H”临时张量。这个规模估计不是实际计算节点测速承诺。

保留旧整叶划分，不把同叶的正反面拆入训练和评价；f85/f86/fRos等原叶组规则继续适用。训练只用预定 train+legacy。dev仅保存结果，不据其选择 DF、r、pair、阈值或模型形式。
旧 confirm/reserve 共50页已公开且被反复分析，只可称『已曝光、拟合外的描述评价』。不再称新盲测、未见测试或重新恢复 reserve 资格。ZL/IT是同一手稿的两个转写，不是两个独立样本。
逐词成本含每个原单位、稀有身份费和最后EOS，报告bits/完整原词。先页均、再叶内页均、再等叶平均；并列给词数、页数、叶组数、OTHER次数与身份费。按两版各自可用词报告，不能隐式假设跨版槽一一对齐。
每个 DF/版/目标至少报告：对普通ridge的叶均差；目标与全部3个训练近邻参照的逐项差及参照均值/范围；目标在参照中的描述名次；每叶差与配对成本。不给训练近邻名次套未经证明的随机置换 p 值，也不把控制范围称置信区间。
主要可证伪门槛：若FP/KT不优于同DF普通ridge，或收益落在匹配参照的常见范围，『超越一般参数共享』不获支持；若只在一个DF或一个转写显示优势，原样报告敏感性；若数值失败/匹配过差，判为当前设计未解决，不说证伪语言。
若绘叶bootstrap区间，明确其为既有探索后的描述稳定性，不是对所有历史假说的统一新显著性。必须把两个DF、两版、三目标全部展示，不选其中一格写标题。

九、评分前必要校准
1. 小有限Ω穷举短前缀、首步mask、OTHER均匀身份拆分、EOS及未见原单位；完整词加解析尾质量总和为1。
2. FP64解析梯度/Hessian对有限差分、自动微分或独立标量实现；首步与非首步分开检查。用小H同时比较 Cholesky trace 与广义特征值求和；检查展平顺序与L归一特征值。
3. 保持名字任意的已知答案合成：共同预测系数的别名；只有频数/绝对位置不同但无特殊共享的伪别名；后继分布相反的两个身份。固定同频位置对照。要求软融合有能力识别适合/不适合的方向，而不是要求每个随机seed都正收益。
4. 硬共享辅助反例：两个同频身份决定不同后继，硬共享必丢信息；有限软融合可以保留。分开说明这一对照不等于本轮软模型对手稿的结论。
5. 已知完整输出分布下计算真实期望log-loss，检查DF匹配不是把任何压缩都变成胜利。保存全部seed和坏结果，禁止以合成测试挑选最适合手稿FP/KT的DF。

十、为何不改成闭式平方损失 ridge 主分析
优势：固定X下有精确线性平滑矩阵和可计算trace、闭式解、确定性的lambda-DF单调关系，易做独立数值审计；可用作求解器/矩阵运算合成校准。
代价：多响应平方损失的预测可能负值或不和为1。截断/重归一或softmax后，闭式线性估计器的trace不再是最终概率预测的同一自由度。若用 Brier loss 替代完整词log-loss，又改变了当前问题。预定有限多项式特征也可闭式，但交互维度/核谱与一般参数共享仍需控制，不能以『可闭式』获得语义解释。
因此凸多项逻辑主模型更符合完整原串概率问题；承认其DF是局部量，接受有界数值搜索。不要为得到漂亮的有效参数数值而把评价目标改成未经说明的代理任务。
