风图条件化输入与适配器独立审查，版本 1

结论：当前固定输入可用于合同明确限定的、接受目录读法与位置关联后的部分内容测量（C）。未发现必须修改本次冻结输入或适配器的实质错误。本结论不认证图上完整文字（I），不授权或报告任何已执行的真实匹配；I 仍为 NOT_READY。本审查没有名称—正文搜索、矩阵、命中、相位或分数。

一、实际核对范围
输入 SHA256 为 c8a9d2edfed1a26352906d5cd984ce7e3317c4bbaf303852edf7e6b28832dce1。audit_input_v1.py 独立实现 N0、原文空白折叠映射及来源跨度检查；未导入、执行或阅读 build_input_v1.py 的逻辑，仅核它的冻结字节哈希。读取完整私有馆藏 HTML，核对其 SHA 及源位置，不发布整份现代目录。

48 个源字段逐条与历史文本提取、编辑台账核对；39 个编辑注释跨度、96 个嵌入字段副本及 24 个 C/P 对应均一致。每个制度 E0、S1 都有 24 名称、24 说明组、25 块；保留 27 个已知正文片段（其中包括只有逗号的空 token 片段）和 5 个未知片段或块。两制度的正文深度相等；唯一名称变化为 f1v.C08 Austro→Austroafricus，且来自冻结的显式编辑建议。不存在其他替换、Greek 补项或正文补字。

四个编辑未知字段是 f1v.description.C11、f2r.description.C01、C06、C12。各自已知部分完整保留，不跨 unknown 粘接；fri[gi]dus 与 iun[g]etus 的整项受影响词均作为未知，未把残片变成确定词。f2r.C10 明确映到 P07，保留主块与额外内侧小块；f2r.C07 对应 P04，仅一块；f1v.C10 也仅一块。P07 小块完全未知，未投入 flo/flor 等暂定读法。

独立 N0 逐字段复算 NFC、仅 ASCII 大写转小写、合同指定空白及标点边界。实际保留文本全为 ASCII 字符，NFC 未改变长度；全部 token 及源码点/UTF-8 跨度一致。人工检查另确认 i/j、u/v 不合并，非 ASCII 大写不被 ASCII 规则改写，未列入的连字符/括号不被悄悄删除。这不是对尚未出现的所有 Unicode 组合情况作通用实现认证。

二、适配器核对
audit_adapter_v1.py 从冻结适配器的语法树只取 assemble 函数，配以本地惰性记录类；没有导入引擎、调用适配器 main 或任何匹配函数。另用直接遍历及独立 token 来源表逐项比对其输出。四个组装实例均通过，且每例的故意错误位置对应均被拒绝。

每制度 f1v 为 12 名称、12 组、12 块、1 unknown、35 个已知正文 token；f2r 为 12 名称、12 组、13 块、4 unknown、208 个已知正文 token。这里的 token 数是给定目录读法经 N0 后的计数，不是手稿认证词数。两制度合计 486 个已知正文 token 的引擎项及来源映射逐项核准。适配器保存片段范围与片段内 token 序号，而非直接保存逐词图像坐标；该索引可经独立 token 表唯一追溯到精确原文跨度。无额外字形正规化，块边界及 unknown 均保留。

引擎已冻结源码和适配器评分分支只作静态阅读：已知整串出现可提供确定存在；没有已知出现且含未知内容时保持 NA；块间或 unknown 上不建立已证实的跨越。未知内容可能在多个名称单元上同时产生依赖。shared_unknown_identities 仅数正文输入里重复的占位 ID，即使为空也不能解释成单元间独立。适配器另列 unknown_to_unresolved_matrix_cells 并明确这一限制，适当；该字段仅列尚未解决单元，不能解释为未知内容所有潜在因果联系。单元见证与该依赖表本次未运行，待首次实际评分后必须另作逐单元独立复算。

三、条件化测量为何自洽、又止于何处
合同固定目录外层 Latin 名称组成部分，以及未括注正文与各组的关联。未知内容是在这些给定片段之间或另一已定义块中留下缺口。因此，一个完全落于固定已知片段内的出现，不会仅因其他块未知而失去“组内至少出现一次”的性质；其余内容未知时，则不能以没有见到来证明不存在。本审查只核此定义，没有搜寻实际出现。

这项保留假设必须与结果同报。特别是 C06 的 Auroauster [Euroauster]，当前 C 固定未括注的 Auroauster，把方括号内容作 unknown；它并不覆盖“编辑说明实际上应替换前一个词”等所有可能的另一种释读。给定片段外的任意内容及独立单元补全构成宽松外界，并非所有历史文本读法的无条件界，也不保证界端点可同时实现。未知内容在物理空间内能写多少字、不同单元如何共享读法均未得到完整约束；报告不能称这些界为精确可实现范围或概率置信区间。

P07 主块目前有词级、片段级图像支持；目录整段放入该主块是合同明示的 C 条件，并未升级为逐字图像认证。内侧小块保留在同一几何组是保守的范围决定，不证明它与主块同一句、同一功能或同一书手。认出名称不能替代正文完整认证。

因此，今后即使执行成功，也只能解释给定目录条件下的完整名称复现是否提供位置线索；不能推出语义关联不存在/存在、机制排除、伏尼契译文或已开放其文字评分。两叶来自同一书，E0/S1 也不是新的独立样本。

run_v1/audit_receipt_v1.json 是源与 N0 独立复算收据；adapter_audit_receipt_v1.json 是四例转换复算收据。所有冻结源文件前后哈希不变。首次源审计遇零长度“缺失开引号”标记的检查程序错误，修正后通过；首次适配器审计遇本机 Python 不支持 zip(strict=True)，改为等长断言后通过。均为本审查工具问题，未修改原输入、适配器或结果，分别保留说明。
