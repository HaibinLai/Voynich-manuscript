独立数值原型 v1（仅人工域测试）

依赖 Python 3 与 NumPy。未读取主实现或新 K/F 形态值，没有图像判断。
输入 schema=joint_signature_domains_v1；entries 是 F01–F06 到完整四整数签名列表的映射。
每向量按 Q0/Q1/Q2/QJ 顺序，值仅 0/1/2；域必须非空、无重复。
未知须由允许的完整向量表示，不能传四个独立坐标域。输入需先保留条目内部全部互斥/归属约束。
branches.H/H4 各为 {a,b,weight} 列表，weight 用精确分数字符串；强制核对冻结提案的 2同4异／2同2异权重。
人工样例见人工测试输出 artificial_input.json。F02 在所有15对中保留，主量权重为零。

运行（在本目录，所有输出目录必须尚不存在）：
python test_artificial.py --output-dir artificial_tests_v1
python replay.py --input artificial_tests_v1/artificial_input.json --output-dir artificial_cli_v1

独立逻辑：枚举 Ashmole 三条目的完整签名组合；每种组合下分别极值化 Morgan 两条目的完整签名。
全程整数计算，H/H4/差值统一分母32，再化简分数。保留 H、H4、H-H4 的各上下端全六见证，
同一见证下三项量的分维贡献、15个S值和差值恒等式。另列全部15对各自可达区间及配对见证。
绝不将独立配对端点拼成主量，也不将完整条目域拆成四维独立域。
不同目标的极值见证可以不同；报告的边际端点不声称同时发生。
输出必须由 --output-dir 指定新目录；程序拒绝覆盖已有目录。

当前冻结条件主分支 H = 同名均值(2对) − 异名均值(4对)。H4 用同名2对和异名2对。
H−H4=(S36+S54−S14−S16)/4，必须在同一完整赋值核对。
严格完整图上名分支为 null。两量正下界标志只表示给定域上的数值条件，不授权返回伏尼契。
本实现对输入允许域求精确代数极值；如果输入域是保守放宽，结果只是相应保守外界。
不是统计区间、独立历史证据或真实图形可实现性认证。
共享条目跨所有配对只取一个值；若以后存在条目间物理别名或其他跨条目约束，须显式扩展合同，
不能直接把这版独立条目乘积域当成已经处理了该额外约束。

测试使用直接 Fraction 全枚举参考，与消元算法逐端点、逐对及分维分解比较；
包括共同缺少、共享未知抵消、非笛卡尔联合域、F02仅描述和错误输入。
测试收据同时冻结源码和本说明的 SHA256。未跑81^6空域压力测试，也未算真实得分。
