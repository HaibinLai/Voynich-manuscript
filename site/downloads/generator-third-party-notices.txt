5145f526b52741a6dca14201147f687e62c7162e.
https://github.com/greshko/naibbe-cipher

2. SelfCitationTextgenerator
Copyright (c) 2019 Torsten Timm; MIT license retained at third_party/timm/LICENSE.
Commit a6ede2202dd7ad6285ce2c007bf22c2a0e7709b7.
https://github.com/TorstenTimm/SelfCitationTextgenerator
Citation: Timm, Torsten, and Andreas Schinner. A possible generating algorithm
of the Voynich manuscript. Cryptologia 44(1), 1–19 (2020; online 2019).
https://doi.org/10.1080/01611194.2019.1596999
Original Java source remains intact. An isolated build disables its unrelated
whole-manuscript dictionary diagnostic, and run configurations change the seed
line/output path/random seed as documented. Seed f1r activates the author's A
branch; the original default f103v activates B.

3. Latin plaintext
Julius Caesar, De bello Gallico, edited by T. Rice Holmes, Oxford: Clarendon,
1914; electronic edition from the Perseus Project, Tufts University.
https://github.com/PerseusDL/canonical-latinLit/blob/master/data/phi0448/phi001/phi0448.phi001.perseus-lat2.xml
The source XML explicitly states CC BY-SA 4.0:
https://creativecommons.org/licenses/by-sa/4.0/
Upstream license text retained at third_party/perseus/license.md.
Changes: remove editorial note/head/speaker elements, normalize to ASCII and
lowercase; Naibbe additionally merges J/I and K/C and rewrites W as UU, removes
word boundaries and punctuation, and selects the first 24000 letters. Encoded,
decoded and normalized Caesar-derived text files in data/ are distributed under
CC BY-SA 4.0 with this attribution. Summary numbers and original project code
are separate from the upstream text license.
